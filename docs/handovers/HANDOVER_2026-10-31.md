- Sitemap `/blog/yazar/almanya101`'i her zaman listeler ama sayfa içerik yokken/sorgu hata verirken `noindex` olabilir (`app/sitemap.ts`, `blog/yazar/[authorSlug]/_components/siteAuthorContent.ts`).
- `lib/corner.ts` yayın ve oluşturma tarihi yoksa "şimdi" tarihi uyduruyor (satır ~204); sitemap/RSS/JSON-LD'ye yansır.
- Kök `/[authorSlug]` kabuğu her bilinmeyen tek segment için DB sorgusu yapıyor: sorgudan önce slug regex'i (`^[a-z0-9-]{2,80}$`) ve kısa önbellek eklenebilir.
- JSON-LD `@id` değerleri `SITE_URL`, sayfa URL'leri `CANONICAL_SITE_URL` ile kuruluyor; `NEXT_PUBLIC_SITE_URL` sonunda `/` olursa uyumsuzlaşır.
- `AdminModal` hiçbir yerde kullanılmıyor; `AdminTabs` artık ARIA tab değil, `aria-pressed` buton grubu (tam tablist için çağıranlarda `tabpanel` gerekir).
- Software Hub: `softwareHub/api.ts` içinde `loadAdminAuth` kopyası (`lib/admin/clientAuth` ile birleştirilebilir), `escapeHtml` çıktısı JSX'te iki kez kaçırılıyor, bazı bağlantılar 44 px hedefin altında.
- `app/admin/layout.tsx` içindeki `beforeInteractive` bayrak script'i üretimde header/footer'ın bir an görünmesine yol açıyor mu, bakılmadı (dev modunda gözlenmedi).
- E2E: araç sayfalarında rastgele React #418 (hidrasyon) hatası. `origin/main`'de de çıkıyor (3 çalıştırmada 1-2 test, her seferinde farklı sayfa); birleştirmeden bağımsız, ayrı araştırılmalı.

## Çalışma ortamı notları
- Node 20, `npm`. Teslimden önce `npm run lint`, `npx tsc --noEmit`, `npm run test:unit`, `npm run build`.
- Paralel oturumlar ana dizini kullandığı için işi `git worktree` ile ayır (`.claude/worktrees/<ad>`). `node_modules`'u ana dizine junction ile bağla (`mklink /J`) ve silerken önce `/s`'siz `rmdir` ile bağlantıyı kaldır; aksi halde ortak `node_modules` silinebilir. `.env.local`'i worktree'ye kopyala (Git'e girmez).
- `.claude/worktrees/blog-seo-geo` klasörü dosya kilidi yüzünden diskte kaldı (Git'ten silindi, izlenmiyor). Elle silinebilir.
- Canlı DB'ye yazma: `psql` yok. `pg` paketini proje dışında bir klasöre kur, `.env.local`'daki `DIRECT_CONNECTION_STRING` ile Node'dan bağlan, önce `BEGIN`...`ROLLBACK` ile kuru çalıştır, sonra `COMMIT`. Adımlar `MIGRATIONS_STATUS.md` içinde. Bağlantı dizesini çıktıya yazdırma. Salt okunur sorgular için `BEGIN READ ONLY`.
- Üretim build'ini yerelde denemek için: `npm run build` sonra `npx next start -p <port>`; dev server aynı `.next` dizinini kullandığı için ikisini aynı anda çalıştırma. Admin giriş görüntüleri için betik `ADMIN_PANEL_PASSWORD`'u `.env.local`'dan okuyup `sessionStorage` (`dad_admin_auth_v1`) anahtarına yazar; şifreyi konuşmaya veya loga yazma.
- Hesap notu: Supabase MCP bu makinede başka bir hesaba bağlı, almanya101 projesini görmez; DB işleri doğrudan bağlantıyla yapılır.
